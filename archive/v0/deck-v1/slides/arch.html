Read left to right. Data comes from tools I already use. Connectors and scripts make it readable; where no connector existed, for TickTick, I built one. Scheduled agents and on-demand plugins do the work. Results land in files and Notion, and the next run reads those first. The color is the important part: blue is Python doing work that must be exactly right, plum is where I let the model make a judgment call, violet is a mix, amber is me.
