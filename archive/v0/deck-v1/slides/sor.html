6

logged incidents where an undated note in memory was later read as fact

One nearly shipped a plugin release under a version number that never existed. Another sent a task list to re-rank database fields that turned out to be empty.

The rule now: every fact records how and when it was verified.

This is the source-of-truth conversation I had with a franchise owner, implemented on my own system. The same contact lived in four tools and drifted. The fix was a table every agent loads: one owner per data type, and automations are barred from reading a mirror, even one I still use as my own interface. The right-hand side is the less obvious lesson. My agents read notes I and they wrote earlier. Six times, a confident undated note was treated as fact. So memory gets the same discipline as data: every claim says how and when it was checked.
