Two calls I overruled

Tone-mapping. The agent’s first develop shifted hue in bright skies. I switched it to luminance-preserving tone-mapping.

Projection. Its default bowed the foreground on wide scenes. Projection is now chosen per scene from the measured field of view.

Stack: ExifTool, Python with uv, rawpy, OpenCV and the Hugin command line. Idempotent, with retries for cloud files that were not yet downloaded.

github.com/anewt225/panorama-automation · case study and reflection in the repo

This one is about working with a coding agent the way an FDE works with a client’s tooling: delegate the mechanics, keep the judgment. The agent wrote the time repair, geotagging and batch stitching. I owned the quality bar. Twice its defaults were wrong in ways only visible at full resolution, and I changed the approach rather than accepting the output. I also reviewed all 36 results myself. The repo has a written reflection on exactly what I owned versus what the agent did.
