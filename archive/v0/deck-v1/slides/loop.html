This is the answer to “how is the workflow actually implemented.” It is a numbered step file the agent runs unattended every morning. Three things to point out. Step 1.5: most days are quiet, so two cheap checks decide whether the expensive work runs at all. Step 2.5: a plain text ledger of Gmail thread IDs makes it idempotent, so a re-run never double-logs and never needs a Notion search to dedupe. Step 3: memory is edited surgically and closed items are demoted to topic files, never deleted, which keeps the current-state file short enough to be followed reliably. Next I would move the top 3 ranking into a scored function in code and back-test it against the 52 saved days.
