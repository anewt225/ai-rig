Everything here runs from one plugin I wrote: 4 skills and 13 commands, with the target role passed in as a parameter, plus an event-prep skill drafted from six real events this fall. Seven linked Notion databases hold the data: opportunities, companies, contacts, communications, interviews, tasks and sprints. Notion wins any disagreement; HubSpot is my interface only and automations never read it. Networking events run in four steps: vet the event (what the ticket actually includes, who is in the room, go or skip), prep (every session scored MUST to SKIP, speakers tiered by helpfulness and influence, calendar blocks linked to a brief), debrief from a template, then follow-ups logged to Notion. Resumes and cover letters are scored before and after tailoring, so every change is measured. The debrief collects my self-rating before the model’s analysis. The capture run is inactive for now because unattended runs stall on a write approval.
