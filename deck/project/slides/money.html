Same pattern as the other workflows: code does anything that must be exact, Claude interprets, and I decide. The finance pipeline parses each institution’s export into one schema, appends to a master ledger keyed by a hash so re-runs never duplicate, and checks every account’s balance before writing a reconcile report. The tax assistant is a plugin with five skills that organizes documents, runs the calculations in code and writes step-by-step filing guidance; I file. The kitchen inventory is a Notion database of about 190 items kept current from zone photos and receipts: Claude previews every change and writes only after I approve, and a restock checkbox drives the grocery list. Travel covers the panorama pipeline (2,394 photos time-corrected and geotagged, 38 raw bursts stitched), a trip dashboard, itineraries, and the Baldwin audio walking tour.
