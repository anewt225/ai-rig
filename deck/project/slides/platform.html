Rules I build by

  1. A forcing cadence turns logging into decisions
  2. Numbers come from scripts, judgment from the agent
  3. Actions, not status
  4. Automate the boring ceremonies, not the judgment
  5. One owner per entity
  6. Grade every count by evidence
  7. Verify it myself; date every claim
  8. Safe to re-run; nothing deleted

Data source reconciliation: Notion owns roles, contacts and messages; mirrors are for people, never automations.

The rules come from my own notes: the first four from an article I am drafting on running agile ceremonies for one person, the rest from the operating model I keep for the system. A precise note on rule 2: inside a Claude routine the agent also carries out fixed steps, like checking a ledger or writing a dated file, through tool calls. Anything numeric that has to be right, such as time totals or ledger balances, is computed by Python scripts before the agent sees it. The site tags every step as script, agent action, agent judgment or me. The full reconciliation table covers twelve data types, each with a conflict rule.
