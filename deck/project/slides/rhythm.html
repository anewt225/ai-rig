The diagram is one element: delete it and the table widens to fill the page. Read the diagram as a daily loop inside a weekly sprint. Every morning the productivity sync pulls what changed since yesterday and writes the daily standup: the top 3 actions and the morning brief with one outreach draft. I do the work, and the next sync picks up what moved. On Sunday, seven daily files and the week’s measured time feed the retro; I reflect on paper; the week-ahead plan goes back into Monday’s sync. Blue is code, plum is Claude, amber is me. Agents never call each other: each run writes a dated file the next run checks for. The sync exits early on quiet days, dedupes email against a ledger of thread IDs, and never deletes anything. The retro writes null, not zero, for unknown numbers, and counts a conversation as held only with evidence.
