Read the diagram as a daily loop inside a weekly sprint. Every morning the productivity sync pulls what changed since yesterday and writes the daily standup: the top 3 actions and a morning brief with one outreach draft. I do the work and the next sync picks up what moved. On Sunday, seven daily files and the week’s measured time feed the retro; I reflect on paper; the week-ahead plan goes back into Monday’s sync. Agents never call each other: each run writes a dated file the next run checks for. The sync exits early on quiet days and dedupes email against a ledger of thread IDs. Time tracking is pure Python on Windows Task Scheduler; the retro reads its 2 KB summary and never recomputes it.
