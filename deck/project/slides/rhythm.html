Blue steps are code, plum steps are the model, amber steps are me. Agents never call each other: each run writes a dated file and the next run checks for it, so every hand-off can be inspected and re-run alone. The standup exits early on quiet days after two cheap checks, dedupes email against a plain-text ledger of thread IDs, and never deletes anything. Time tracking exists only to feed the retro’s planned-versus-actual comparison: four Windows jobs and eight Python scripts compute everything, and the retro reads the summary without recomputing it. The scorecard writes null, not zero, when a number is unknown, and a conversation counts as held only with evidence. Full spec for each piece is on the site.
